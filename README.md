# Rue & Ritual

A clothing and beauty storefront with product filters, a shopping bag, and a simulated checkout.

Run the store locally from the repository root:

    python -m http.server 8080 --bind 127.0.0.1 --directory dist

Open http://127.0.0.1:8080/ in your browser. At checkout, select **Use sample details** to try a demo order. The demo collects no payments.
